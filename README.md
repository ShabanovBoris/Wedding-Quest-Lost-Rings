# Wedding Quest: Lost Rings

Браузерная 2D action-platformer игра на годовщину свадьбы. Проект находится на стадии проектирования; игровой код ещё не создан.

## Старт для агента

1. Прочитать [AGENTS.md](AGENTS.md).
2. Прочитать [полное ТЗ](docs/GAME_SPEC.md) и [план разработки](docs/IMPLEMENTATION_PLAN.md).
3. Проверить [текущий статус](docs/STATUS.md).
4. Начать с этапа 0, затем реализовать graybox и vertical slice. Готовые ассеты предоставляет владелец по ASSET_HANDOFF.md; при отсутствии материалов продолжать на технических заглушках и тишине. Coding-агент не производит графику или аудио.
5. Обновлять статус, решения, реестр ассетов и QA после каждого инкремента.

## Два независимых контура

Владелец + внешний ИИ готовят графику, анимации, музыку, SFX и личный контент по ASSET_PRODUCTION.md. Coding-агент принимает готовый пакет с manifest.json по ASSET_HANDOFF.md, реализует игру и проверяет интеграцию. Пакет может поступить сразу или партиями; локальная папка asset-delivery/ исключена из Git. Личные оригиналы остаются отдельно. Без готовых P0 материалов релиз не закрывается.

## Приватность

Репозиторий публичный на момент инициализации. Не коммитить личные фото, исходное аудио, имена, даты, поздравления, ключи и другие приватные материалы. Использовать локальный каталог `private-input/` вне сборки и git. Для персонализированной версии нужен отдельно согласованный закрытый режим доступа; скрытая ссылка не является защитой. Не публиковать игру без разрешения владельца.
